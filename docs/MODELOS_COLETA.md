# Modelos 3D da coleta (Vale dos Ecos)

Lista de pedidos para o gerador (Tripo ou Meshy) que substituem as formas feitas por código no vale.
Os prompts estão em inglês porque os geradores entendem melhor. Coloque o **estilo comum** no fim de cada prompt.

## Estilo comum (colar no fim de todo prompt)

```
stylized low-poly fantasy game asset, cozy storybook style, soft pastel hand-painted colors, gentle cel-shaded look, clean readable silhouette from a 45-degree top-down camera, single object centered, standing on its own small base, no ground plane, no background, no text, no characters
```

## Regras de exportação

- **Formato:** .GLB com textura (1024 px), sem animação. Nome do arquivo exatamente como na lista.
- **Tamanho:** até ~3 mil triângulos (use a opção low-poly / "smart low poly" do gerador); o jogo escala sozinho.
- **Base:** pivô na base, em pé. A frente não importa (o jogo gira cada cópia).
